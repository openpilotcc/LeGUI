# 遥操作与相机

遥操作 = 你移动**主臂（示教臂）**，**从臂（执行臂）**实时跟随。这是确认校准效果、演示机械臂、以及在录制前热身的好方法。

## 启动遥操作

前提：两条臂都已完成校准（机器人条目显示绿色「就绪」）。

1. 首页选好机器人，点击 **「遥操作」** 按钮，页面自动跳转到遥操作页。
2. 从臂上电并跟随主臂。**缓慢移动**——从臂会镜像你的动作。
3. 随时点击页面上的 **停止** 按钮结束（也可以在首页机器人卡片上操作）。

!!! warning "安全提醒"

    启动后从臂即上电并跟随主臂运动。确保从臂周围没有障碍物，移动主臂时动作平稳，避免从臂高速甩动。

## 相机实时画面

遥操作页可以把该机器人配置的相机画面实时显示出来：

1. 打开页面右上角的 **相机开关**（默认关闭）。
2. 每台配置的相机会出现一个实时画面卡片；画面由**后端采集、以视频流推送给浏览器**——局域网内纯 HTTP 访问也能看到，无需任何权限弹窗。
3. 画面卡住或黑屏时点 **重新扫描/重试** 按钮。

!!! note "与校准页相机的关系"

    遥操作页显示的相机就是校准流程里配置的那些（名称、编号、旋转角度一致）。要增删相机，回校准页操作。

## 主臂与从臂姿态对不上？

姿态对应关系由校准决定。如果遥操作时从臂没有镜像主臂的姿态：

1. **重新校准两条臂**，特别注意校准开始时的「确认中位姿势」步骤——那个姿势就是零点，两条臂都以官方中位姿势为零点后，姿态才会一一对应。
2. 确认两条臂的型号一致（SO-101 主臂与从臂的关节布局相同）。

## 从臂保持不动

不移动主臂时从臂会保持当前位姿。想结束并让电机断电，点 **停止**；再次启动时从臂会上电并锁定新的当前位姿。
