# 校准机械臂

校准让应用了解每个关节的行程范围与零点方向，是首次使用（以及更换机械臂、重装系统后）必做的步骤。主臂（示教臂）和从臂（执行臂）各自校准一次。

## 开始前

1. 首页下拉框输入机器人名称（如 `bo`）回车创建并选中机器人。
2. 点击机器人条目旁的 **齿轮 ⚙** 进入校准页。
3. 设备类型选择 **主臂（示教臂）**，端口填 `/dev/ttyACM0`（不确定就点 **Find** 自动检测）。
4. **确认机械臂电源已接通**——舵机没电时串口上不会有任何应答，校准会立刻失败。

## 中位姿势确认（重要）

点击「开始校准」连接成功后，第一步不是动关节，而是**把整条机械臂摆到官方图示的中位姿势**（参考页面下方的演示视频）：所有关节都处于行程范围的正中间。

摆好后点击 **「中位已摆好 — 开始记录行程」** 确认。

!!! warning "为什么这一步很关键"

    确认中位时的姿势会成为每个电机的**零点**。主臂和从臂各自以官方中位姿势为零点，遥操作时两者姿态才会一一对应——如果跳过或随手摆摆，遥操作时主臂和从臂的姿势就会对不上。

## 记录行程范围

确认中位后进入记录步骤：

- **逐个转动每个关节**走完它的全部行程（从一端到另一端），关节旁出现 ✓ 即表示行程记录足够完整。
- **`wrist_roll`（手腕旋转）无需记录**：它是连续旋转关节，系统自动赋予全编码器行程，不会被限位。
- 全部关节出 ✓ 后点击 **「保存校准」**。

!!! tip "已有校准文件"

    之前在这台电脑上校准过的机械臂，可以在齿轮菜单里选「关联已有校准文件」直接复用，无需重新校准。

## 校准从臂

主臂完成后，设备类型切换为 **从臂（执行臂）**，重复「确认中位 → 记录行程 → 保存」。

## 相机配置（可选）

在校准页下方的「已关联相机」区域：

1. 打开相机开关，从「可用相机」下拉框选择一个相机编号。
2. 填写相机名称（如 `workspace_cam`），点击「添加相机」。
3. 相机装倒了或侧装了，选择对应的 **旋转角度**。
4. 可以设置 **基准帧**：保存一张参考画面，下次校准时以半透明叠加在实时画面上，方便对准支架。

配置好的相机会在遥操作和录制时使用；画面由后端以视频流方式提供，局域网纯 HTTP 访问也能看到。

## 常见问题

- **开始校准立刻报错「Could not connect on port ...」**：设备没插好或没上电。串口名来自上次保存的缓存，不代表设备在线——检查电源与 USB 线后重试。
- **报「Missing motor IDs」/ 总线无应答**：电机没电（检查电源）、信号线松脱，或端口选错。
- **提示电机不连续（Motor discontinuity）**：校准过程中串口闪断，重新插拔 USB 后重试。
