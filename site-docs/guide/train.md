# 训练策略

录好数据集后，训练页把回合变成机器人可运行的策略。LeGUI 支持 LeRobot 的全部策略（**SmolVLA**、ACT、Diffusion、π0 系列、GR00T 等）。

## 训练前

- 至少一份本地数据集（录制或从 Hub 下载）。
- 本地 GPU（如 RTX 4090 完全够用），或登录 Hugging Face 后使用云端算力。

## 训练步骤

1. 首页 **创建模型 → 训练** 进入训练页。首次进入会检查训练依赖并提示 **立即安装**——点它，等安装完成。
2. **Essentials**：
   - 选择你的数据集；
   - 策略选 **SmolVLA**（视觉-语言模型，理解语言指令，效果好）或 **ACT**（轻量快速，适合第一次跑通）；
   - 设置训练步数（几千步起步）与批大小。
3. **算力目标**：选 **本地 — 你的机器（免费）**；或选云端租用（需已登录 HF）。
4. 高级参数保持 **使用策略默认值** 即可，有经验再调（学习率、批大小、AMP 等）。
5. 点 **开始训练**。

## 观察训练

- 首页任务卡片实时显示进度、损失曲线和日志。
- 训练指标默认通过 **Trackio** 上报（lerobot v0.7 起，替代了旧的 W&B）。
- 达到检查点保存频率后，任务页会出现 **可选检查点** 列表。

## 运行训练好的策略

- 有可用检查点后，模型卡片上出现绿色 **播放按钮**。
- 点击（或在推理页选检查点）→ 确认硬件 → 从臂将按配置时长**自主执行**学到的任务。
- 结束后从臂保持位姿；想再跑一次直接再点。

!!! tip "第一次训练建议"

    先用 ACT 跑通全流程（训练快、显存小），确认「录制 → 训练 → 运行」闭环没问题，再用 SmolVLA 冲效果。

## 常见问题

- **训练页提示「未安装训练扩展」**：点「立即安装」，安装完按提示重启服务。
- **报 CUDA / 显存不足**：减小批大小，或改用云端算力。
- **想从某个检查点继续训练**：Essentials 里勾选「从检查点恢复」并选择检查点。
