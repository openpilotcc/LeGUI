# 录制与数据集

录制 = 你操控主臂示范任务，从臂跟随执行，所有关节状态与相机画面被采集为一份 **LeRobot 数据集**。数据集是训练策略的原料。

## 录制前

- 两条臂已校准（首页机器人显示「就绪」）。
- 相机已在校准页配置好（录制会用到它们）。
- 想清楚任务的**自然语言描述**——它会被存进每条数据，也是训练时的指令（如“把红色方块放到蓝色区域上”）。

## 录制配置

进入录制页（首页 **录制** 入口）：

| 字段         | 说明                                       |
| ------------ | ------------------------------------------ |
| 机器人       | 选择已校准的机器人                         |
| 数据集名称   | 小写字母/数字，本地目录与 Hub 仓库名都用它 |
| 回合数       | 计划录制的回合数量，建议 10~50 个起        |
| 每回合时长   | 一次任务尝试的时长（秒）                   |
| 重置时间     | 两个回合之间重新摆放物体的停顿             |
| 任务描述     | 训练时给策略看的指令                       |
| 流式视频编码 | 建议保持开启（实时编码，几乎即时保存）     |

## 录制流程

1. 点击 **开始录制** —— 从臂上电，倒计时后回合开始。
2. **用主臂带从臂完整执行一次任务**。
3. 回合结束时点 **结束回合** —— 该回合立即落盘。
4. 重新摆放场景物体，点 **开始下一回合**，重复。
5. 全部录完点 **停止录制** —— 会话结束，自动跳到上传页。

!!! warning "中断与异常"

    中途出错点「停止录制」：已保存的回合会保留，不会丢。若页面提示会话状态异常，先停止再重新开始，不要连续点多次开始。

## 数据存在哪里

- 数据集自动保存在服务器本地 LeRobot 标准目录（`~/.cache/huggingface/lerobot/`），不上传也不会丢。
- 每回合包含全部关节状态 + 所有相机的视频帧 + 任务描述。

## 上传到 Hugging Face Hub（可选但推荐）

上传页支持一键推送。需要服务器上的 `hf` CLI 已登录：

```bash
hf auth login
```

粘贴一个有 **write 权限**的 token（页面右上角「HF 未配置」点开也有指引）。上传时可选公开或私有；之后随时可以用页面里的数据集浏览器**回看每个回合的每一帧**、给回合批量改任务描述、合并或移动回合。

跳过上传也没关系——以后随时手动上传，或在训练时直接用本地数据集。
